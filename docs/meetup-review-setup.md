# 후기 시트 연결

화면: /about/language-exchange/play, API: /about/api/meetup-review.
현재 연결 설정 전에는 저장 성공으로 표시하지 않습니다. 기존 게딱지 백엔드는 사용하지 않습니다.

1. 제공한 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `docs/meetup-review.gs` 전체를 편집기에 붙여넣고 저장합니다.
3. 비밀값을 생성합니다: `openssl rand -hex 32`.
4. Apps Script **프로젝트 설정 → 스크립트 속성**에 `MEETUP_REVIEW_SECRET`을 추가하고 위 비밀값을 넣습니다. 비밀값은 채팅이나 공개 파일에 붙이지 않습니다.
5. **배포 → 새 배포 → 웹 앱**에서 실행 사용자는 **나**, 액세스는 **모든 사용자**로 설정합니다. 본인 계정으로 권한을 승인합니다. 시트 자체는 비공개를 유지합니다. 엔드포인트는 외부에서 호출 가능하지만 비밀값이 맞아야 기록합니다. 조회 기능은 제공하지 않습니다.
6. 배포된 `/exec` URL을 복사합니다. 웹 호스팅의 서버 환경변수에 다음을 설정합니다.
   - `MEETUP_REVIEW_SCRIPT_URL`: 복사한 URL
   - `MEETUP_REVIEW_SECRET`: 스크립트 속성과 동일한 비밀값
   로컬에서는 `.env.local`에 설정합니다. `NEXT_PUBLIC_` 접두어를 붙이지 않습니다.
7. 웹사이트를 재배포합니다. 로컬은 개발 서버를 재시작합니다.
8. 본인이 테스트 후기 1건을 제출해 Reviews 탭에 들어오는지 확인합니다. 연결 확인 전에는 실제 저장 검증이 완료된 것이 아닙니다.

열 제목은 첫 저장 때 자동 생성합니다. 모임 날짜는 참가자가 확인하여 입력합니다. 닉네임은 선택이고 후기는 운영자에게만 전달되며 사이트에 공개되지 않습니다. 폼 제출 ID로 네트워크 재시도의 중복 저장을 막습니다. 본인 인증 또는 1인 1회 제한은 아니며 공개 API의 대량 요청 차단은 호스팅 측 요청 제한 설정이 추가로 필요합니다.

공식 배포 안내: https://developers.google.com/apps-script/guides/web
